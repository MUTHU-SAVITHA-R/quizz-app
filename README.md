**Quiz Application**
This is a web-based Quiz Application developed as part of my Frontend Development Internship.
The application allows users to attempt quizzes, view their scores, and improve their knowledge through an interactive and user-friendly interface.

🚀 **Features**
Interactive quiz interface
Multiple-choice questions
Real-time score calculation
Instant feedback after answering
Responsive design (mobile, tablet, desktop)
User-friendly and clean UI
Restart quiz option

🛠️ **Technologies Used**
HTML5 – Structure of the application
CSS3 – Styling and responsive layout
JavaScript – Quiz logic, score calculation, and interactivity

📂 **Project Structure**
index.html – Main quiz interface
style.css – Styling of the quiz app
script.js – Quiz functionality and logic
